# Check

## Описание

Check — это Java-приложение, разработанное с использованием Spring Boot и Spring Security. Оно предназначено для управления студентами и рассылками по электронной почте. Приложение поддерживает регистрацию пользователей, подтверждение почты, а также автоматическую отправку рассылок по расписанию.

## Функциональность

- **Роли пользователей**:
    - **Админ**:
        - Может добавлять, изменять и удалять студентов.
        - Может создавать и управлять рассылками.
    - **Студент**:
        - Может изменять только свои данные.

- **Регистрация и подтверждение почты**: Пользователи могут зарегистрироваться, после чего им отправляется письмо для подтверждения адреса электронной почты.

- **Автоматические рассылки**: Рассылки выполняются автоматически по расписанию, используя cron-выражения.

## Технологии

- **Java 8**
- **Spring Boot 2.7.8**
- **Spring Security**: Для аутентификации и авторизации пользователей.
- **Liquibase**: Для управления миграциями базы данных.
- **PostgreSQL**: В качестве базы данных.
- **Lombok**: Для упрощения работы с Java-кодом.
- **Aspose**: Для работы с документами и отправки писем.
- **JUnit и Mockito**: Для тестирования.
